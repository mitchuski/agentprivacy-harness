## What was built

- **The wizard framing** (README + ADOPTION): the pathway named as what it
  is — a setup wizard whose install is a mage. The corpus never travels;
  the method does, as a constitution the conformance gate re-proves
  wherever it lands. Eight reflections listed as evidence.
- **The Observe lane** (`WIKI.md` + three tools, zero dependencies):
  - `tools/wiki_emit.mjs` — ledgers → FedWiki page JSON: hub, verdict-first
    run pages, killed levers, chronicles, and a graph page. Deterministic —
    re-run = byte-identical.
  - `tools/wiki_install.mjs` — derive (spellweb) → project (emit) → install
    into a local farm host. Idempotent and additive: steady-state writes
    zero files; forked or hand-authored pages are never deleted; an
    existing `owner.json` is never overwritten.
  - `tools/wiki_proxy.mjs` — the tailnet pattern generalised: one localhost
    port per site by Host rewrite, an allowlisted front door, and not one
    line that touches tailscale — publishing a port is the door.
  - The knowledge-graph layer: `/assets/spellweb/graph.json` as the
    agent-forkable sibling of the pages — one fetch and a visiting agent
    holds the instance's whole shape. Pages for people, the graph for
    agents, both from the same ledgers, so neither can drift.
- **The sample federation** (`examples/wiki-farm/`): a servable farm data
  directory in the box — `agentprivacy.localhost` as the hand-authored hub
  space (welcome, the harness, the origin, start-your-own) and
  `field-guide.localhost` as the spar's generated projection, rosters and
  cross-site references wired, no `status/` committed (ownership is claimed,
  never shipped). A fresh clone serves a wiki neighborhood on day one.
- **The web, re-rendered in the upstream's language.** The First Person
  judged the first generated web poor, and it was: weak repulsion, no
  collision, monochrome edges, physics running live from a cold start.
  `tools/spellweb.mjs` was rebuilt in the hand-curated spellweb's visual
  language — its theme, typed node visuals (verdict-colored levers, domain-
  colored lenses), typed edge styles — with the layout **settled before
  first paint**, ring geometry by layer, hover-tracing, an inspector,
  legend filters, and search. Same walkers, same dialect, zero deps. And a
  new `--workshop` mode derives the whole harness as one web: the
  inscription at centre, trusts + rules + seats, the engine and its lanes,
  and all sixteen paths colored by weight.
- **The star** (`tools/star.mjs`): the soulbis star, in the harness — the
  workshop seated on ℤ/64ℤ (declared vertex, or a labeled provisional),
  the anchor forced by the law (63 XOR v, never chosen), and every

  re-run = re-true, and colour never proof (FLEET §6 held). Emits
  `star.v1` JSON + a rendered instrument; `wiki_emit` publishes both, so
  every instance site carries its graph *and* its star.
