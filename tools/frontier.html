What the frontier is

The frontier is an instance's sole authority for numbers, drawn as a moving ceiling: a line that steps down only when a human keystone folds an audited win — never on an agent's own word. Every dot on it carries its own proof: the tests that passed it were derived by hashing the proposal together with a secret its author never saw, so nothing on this line was graded by the hand that made it.

The purpose is verifiable saving. Each fold is the same guaranteed content in fewer words, constraints, or bytes — which, for an agent runtime, means fewer tokens every time the artifact is used: smaller contexts, cheaper processes, and — where the gate is a census — a proof that nothing was lost to buy the saving. And because each saving seals as a κ-addressed node, and each verification of it can be minted as a signed edge, frontiers are how trust graphs form: an agent can trust the smaller artifact, and the process that produced it, without re-deriving its whole history.

The words on this page

baseline
the measured start — what the counting rule said before any round ran.
lever
one named, specific change a proposer put forward.
the gate
the held-out exam: witnesses hashed from the proposal plus a run secret, so the proposer cannot tune to them.
census / sample
whether the gate probed every enumerable fact (detection 1.0) or a drawn subset — labelled on each dot, never upgraded after the fact.
VALIDATED
full gate pass + hard constraint intact + a frontier beat. All three, or nothing.
MIRAGE
passed the author's own probe, failed the real gate — worth exactly zero at any score. Named, never softened.
fold
the keystone accepting a validated lever into the artifact — once, with the conformance gate green before and after. Only folds move this line.
killed lever
a change that died on evidence — filed as prominently as a win, so no one digs there twice.
R(t)
best ÷ baseline — the moving ceiling as a ratio, the model's own term for it.
κ artefact
the sealed record of a fold: content-addressed, never trusted, only re-derived.

The full record of every fold lives in the instance's own ledgers; this page carries the numbers and their proofs, not the narratives.
