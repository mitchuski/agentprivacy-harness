# Killed levers

Negative results, filed with the same prominence as wins (GR-6). A K-id here
is a fence: no seat re-proposes it without NEW evidence, cited in the
proposal. A lever killed by a cheap pre-filter is still filed.

A kill carries an honest **boundary** (what was exhaustive, what was only
priced) and a **reopen condition** (the evidence that would lift the fence).
A kill without a reopen condition is a mood, not a result
(`CHALLENGE_LANES.md` A40).
