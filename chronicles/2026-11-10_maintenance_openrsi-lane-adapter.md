# Maintenance · 2026-11-10 · A tool-bearing seat driver and an OpenRSI lane adapter

Maintenance, not research: no seat, no round, no verdict. OpenRSI (yukon.org/openrsi) ranks research-agent harnesses by the progress they make per model credit on an assigned problem. A run is given one task file, a workspace, a metered model gateway and a trusted `evaluate` command, and is then left alone until the budget or the clock ends. This session made the harness enterable that way.

**1. `drivers/claude_code.mjs`**, a seat driver with tools. The API drivers exchange text and JSON only, so their assay seat can describe a gate but never run one. Here each seat is one headless Claude Code session with shell and filesystem tools, pointed at whatever Messages endpoint the caller assigns. Same `rt` contract. It reads no credential. It handles three gateway signals a model never sees because a CLI exit is not feedback: `run_action=stop` (the run is over, no retry), a retryable error (bounded backoff), and a reservation larger than the remaining budget (halve the output cap, once more). A schema repair is one resumed turn in the same session, so the work is not paid for twice.

**2. `openrsi/lane.config.mjs`**, the seat-contract config for the lane. Problem-agnostic: statement, scaffold, candidate paths and library arrive at run time. The Gap is the trusted evaluator, whose test inputs are derived from the frozen candidate; the Gap seat is held by code and binds each verdict to its committed proposal by hash (legacy mode, no witness bank of ours). Two finders, `dominant-term` and `structure`. One round per engine run.

**3. `openrsi/enter.mjs`**, the keystone. Scaffolds an instance with `tools/new_instance.mjs`; runs a canary phase (the assay seat builds the first fully valid candidate; no frontier exists before it); then rounds through `engine/dual_agent_loop.mjs`. Between rounds it folds, and trusts no seat to: it re-runs the evaluator on each frozen scratch that claims a win, and only valid-and-better moves `frontier.json` and the candidate path. Every evaluator run and fold is a row in a hash-chained `runs/ledger.jsonl`. Measure, Gap and Chronicle are held by code. With no gateway (a packaging smoke) the stub driver holds the model seats.

**4. `openrsi/pack.mjs` and `openrsi/package/`**, the source package. An explicit list of 27 files (engine, Gap tool, seven seat cards, ground rules, trusts, scaffolder and its templates, two drivers, the adapter, a Dockerfile and manifest). No chronicle, fleet catalogue or instance travels. A scan refuses a package that names a problem domain, because an OpenRSI harness must be general-purpose and bundling a lane's research is a rule violation there whoever wrote it. `SEAT_CONTRACT.md` is left out for that reason: its product-objective passage names a lane's score.
